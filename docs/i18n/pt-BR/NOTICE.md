# Atribuição

ViperMesh for Blender inclui trabalho derivado de
[BlenderMCP](https://github.com/ahujasid/mcp-for-blender) por Siddharth Ahuja,
originalmente distribuído sob a Licença MIT.

Os contribuidores do ViperMesh ampliaram essa base com uma sessão MCP persistente,
ferramentas determinísticas de cena, fluxos de trabalho em estágios, integração
orientada para agentes, inspeção estruturada e recuperação de orientação local.

Blender é uma marca registrada da Blender Foundation. Este projeto não é afiliado
à Blender Foundation nem endossado por ela.

Model Context Protocol e MCP são usados de forma descritiva. Este projeto é um
conector open-source independente.

O site de visão geral do projeto inclui a fonte Outfit, distribuída sob a SIL
Open Font License 1.1. Sua licença está incluída em `site/assets/OFL-Outfit.txt`.
O sprite de ícones do site e os ícones de ação do README usam Lucide sob a
licença ISC; a licença associada está incluída em
`site/assets/LICENSE-Lucide.txt`. A arte do ViperMesh é identidade visual, não
uma captura de tela do Blender nem um artefato de benchmark.
