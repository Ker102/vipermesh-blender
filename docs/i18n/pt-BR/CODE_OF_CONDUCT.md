# Código de Conduta

<a id="our-standard"></a>
## Nosso Padrão

Estamos comprometidos com uma comunidade construtiva e livre de assédio. Seja
respeitoso, específico e focado no trabalho técnico. Discordâncias são bem-vindas;
ataques pessoais, assédio, discriminação e interrupção deliberada não são.

<a id="enforcement"></a>
## Aplicação

Os mantenedores podem editar ou remover comentários, issues, commits, código e
outras contribuições que violem este padrão. Violações repetidas ou graves podem
resultar em banimento temporário ou permanente.

Relate preocupações de conduta em privado pelos canais de contato do mantenedor
no perfil do GitHub deste repositório. Os relatos serão revisados com a máxima
rapidez e confidencialidade práticas.
