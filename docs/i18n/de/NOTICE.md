# Attribution

ViperMesh for Blender enthält Arbeit, die von
[BlenderMCP](https://github.com/ahujasid/mcp-for-blender) von Siddharth Ahuja
abgeleitet ist und ursprünglich unter der MIT License verteilt wurde.

Die ViperMesh-Mitwirkenden haben diese Grundlage um eine persistente MCP-Sitzung,
deterministische Szenenwerkzeuge, gestufte Workflows, Agent-Onboarding,
strukturierte Inspektion und lokale Guidance-Abfrage erweitert.

Blender ist eine eingetragene Marke der Blender Foundation. Dieses Projekt ist
nicht mit der Blender Foundation verbunden und wird von ihr nicht unterstützt.

Model Context Protocol und MCP werden beschreibend verwendet. Dieses Projekt ist
ein unabhängiger Open-Source-Connector.
