# Verhaltenskodex

<a id="our-standard"></a>
## Unser Standard

Wir setzen uns für eine konstruktive, belästigungsfreie Community ein. Sei
respektvoll, konkret und auf die technische Arbeit fokussiert. Widerspruch ist
willkommen; persönliche Angriffe, Belästigung, Diskriminierung und absichtliche
Störung sind es nicht.

<a id="enforcement"></a>
## Durchsetzung

Maintainer können Kommentare, Issues, Commits, Code und andere Beiträge, die
gegen diesen Standard verstoßen, bearbeiten oder entfernen. Wiederholte oder
schwere Verstöße können zu einer vorübergehenden oder dauerhaften Sperre führen.

Melde Verhaltensbedenken privat über die Kontaktmöglichkeiten der Maintainer im
GitHub-Profil für dieses Repository. Meldungen werden so zeitnah und vertraulich
geprüft, wie es praktisch möglich ist.
