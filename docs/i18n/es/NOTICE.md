# Atribución

ViperMesh for Blender incluye trabajo derivado de
[BlenderMCP](https://github.com/ahujasid/mcp-for-blender) por Siddharth Ahuja,
distribuido originalmente bajo la MIT License.

Los colaboradores de ViperMesh ampliaron esa base con una sesión MCP persistente,
herramientas de escena deterministas, flujos de trabajo por etapas, incorporación de agentes,
inspección estructurada y recuperación de guía local.

Blender es una marca registrada de Blender Foundation. Este proyecto no está
afiliado ni respaldado por Blender Foundation.

Model Context Protocol y MCP se usan de forma descriptiva. Este proyecto es un
conector independiente de código abierto.

El sitio de descripción general del proyecto incluye la fuente Outfit, distribuida bajo la SIL
Open Font License 1.1. Su licencia se incluye en `site/assets/OFL-Outfit.txt`.
La hoja de iconos del sitio y los iconos de acción del README usan Lucide bajo la licencia ISC;
la licencia asociada se incluye en `site/assets/LICENSE-Lucide.txt`.
El arte de ViperMesh es marca visual, no una captura de pantalla de Blender ni un artefacto de benchmark.
