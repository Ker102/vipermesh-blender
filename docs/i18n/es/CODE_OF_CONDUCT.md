# Código de conducta

<a id="our-standard"></a>
## Nuestro estándar

Estamos comprometidos con una comunidad constructiva y libre de acoso. Sé respetuoso,
específico y enfocado en el trabajo técnico. El desacuerdo es bienvenido; los ataques
personales, el acoso, la discriminación y la interrupción deliberada no lo son.

<a id="enforcement"></a>
## Aplicación

Los mantenedores pueden editar o eliminar comentarios, issues, commits, código y otras
contribuciones que infrinjan este estándar. Las infracciones repetidas o graves pueden
dar lugar a una prohibición temporal o permanente.

Informa inquietudes de conducta en privado mediante las opciones de contacto del mantenedor
en el perfil de GitHub de este repositorio. Los informes se revisarán tan pronto
y confidencialmente como sea práctico.
