# Code de conduite

<a id="our-standard"></a>
## Notre standard

Nous nous engageons à maintenir une communauté constructive et sans harcèlement.
Soyez respectueux, précis et concentré sur le travail technique. Les désaccords
sont bienvenus ; les attaques personnelles, le harcèlement, la discrimination
et les perturbations délibérées ne le sont pas.

<a id="enforcement"></a>
## Application

Les mainteneurs peuvent modifier ou supprimer les commentaires, issues, commits,
code et autres contributions qui enfreignent ce standard. Des violations
répétées ou graves peuvent entraîner une exclusion temporaire ou permanente.

Signalez les problèmes de conduite en privé via les options de contact du
mainteneur sur le profil GitHub de ce dépôt. Les signalements seront examinés
aussi rapidement et confidentiellement que possible en pratique.
