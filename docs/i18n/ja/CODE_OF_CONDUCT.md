# 行動規範

<a id="our-standard"></a>
## 私たちの基準

私たちは、建設的でハラスメントのないコミュニティに取り組んでいます。敬意を持ち、具体的で、技術的な作業に集中してください。意見の相違は歓迎しますが、個人攻撃、ハラスメント、差別、意図的な妨害は認めません。

<a id="enforcement"></a>
## 執行

メンテナーは、この基準に違反するコメント、issue、コミット、コード、その他のコントリビューションを編集または削除することがあります。繰り返しの違反や重大な違反は、一時的または恒久的な禁止につながる場合があります。

行動に関する懸念は、このリポジトリの GitHub プロフィールにあるメンテナー連絡手段を通じて非公開で報告してください。報告は、実務上可能な限り迅速かつ機密にレビューされます。
