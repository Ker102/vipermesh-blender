# セキュリティポリシー

<a id="supported-versions"></a>
## サポート対象のバージョン

セキュリティ修正は、公開された最新リリースに対して提供されます。

<a id="reporting"></a>
## 報告方法

脆弱性について公開の Issue を作成しないでください。リポジトリの Security タブにある GitHub の非公開 **Report a vulnerability** 手順を使用してください。

影響を受けるバージョン、再現手順、影響、提案する緩和策があれば記載してください。情報を公開する前に、メンテナーが調査する時間を確保してください。

<a id="trust-boundary"></a>
## 信頼境界

ViperMesh for Blender は、信頼できるローカルワークステーション向けのコネクタです。

- アドオンは既定で `127.0.0.1` にバインドします。
- MCP サーバーは stdio を介してクライアントと通信します。
- `execute_code` は Blender 内で任意の Python コードを実行できます。
- このコネクタはリモート認証の境界を提供しません。

信頼できる MCP クライアントだけを接続してください。Blender のブリッジポートを LAN や公開インターネットに露出させないでください。また、確認せずに信頼できない `.blend` ファイルを開いたり、信頼できないプロンプトを実行したりしないでください。
