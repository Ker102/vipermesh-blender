<a id="scene-operations"></a>
# シーン操作

<a id="choose-the-smallest-useful-surface"></a>
## 必要な最小限の機能を選ぶ

- 既存のシーンを変更する前に検査してください。
- 現在のタスクに合わせてレジストリを検索または絞り込んでください。
- 要求された変更に合う場合は、名前の付いた決定論的な操作を優先してください。
- 利用可能なツールを組み合わせるよりも、独自の Blender ロジックの方が明確または高機能である場合は、`execute_code` を使用してください。

<a id="group-calls-deliberately"></a>
## 呼び出しを意図的にまとめる

`call_blender_tool_batch` は、既知の大まかな形状を作る場合や、既知のトランスフォームを複数適用する場合など、独立した操作や判断済みの操作に適しています。次の操作が寸法、接触、トポロジー、ビューポートの表示、レンダリング結果に依存する場合は、呼び出しを分けてください。

`run_blender_scene_stage` は、一般的な構築、プレビュー、最終処理を簡潔にまとめられます。各段階の使用は任意であり、カメラや照明を設定する場合があります。現在の見せ方を保持するには、最終処理で `preservePresentation: true` を設定してください。対象を絞った修正や、段階処理の形式に合わない作業には、個別のツールが適しています。

<a id="preserve-user-work"></a>
## ユーザーの作業を保持する

既存のオブジェクト、コレクション、モディファイアー、マテリアル、アニメーション、ファイルパスは、ユーザーが所有する状態として扱ってください。元に戻せる編集を優先し、復元に手間がかかる破壊的な操作の前には、複製や保存によって以前の状態を残してください。

後続の操作で識別が重要になる場合は、分かりやすいオブジェクト名やコレクション名を使ってください。単に好みの階層構造に合わせるためだけにシーンを整理し直さないでください。

<a id="finish-with-evidence"></a>
## 証拠を確認して完了する

完了を報告する前に、要求されたオブジェクトや変更が存在することを確認し、危険性の高い構造上の関係を検査してください。blend ファイルはユーザーが要求した場合に限り、承認された保存先に保存してください。レンダリングだけを行う作業では `blendPath` を省略します。検査やエクスポートには、blend ファイルを保存したり上書きしたりせず、個別のツールを使用できます。準備完了と主張する前に、要求された画像やエクスポート成果物を生成し、確認してください。
