# 視覚的な見せ方

<a id="build-a-useful-feedback-loop"></a>
## 有用な確認と修正の循環を作る

プレビューは、構図、相対的なスケール、向き、見え方、マテリアルの判別しやすさ、接触、照明の方向といった具体的な疑問に答えるために使ってください。判断に影響しないスクリーンショットの繰り返しは避けてください。

参考画像の再現では、小さな細部に時間をかける前に、画面内の大きな基準要素を比較してください。その後の調整では、想定するカメラから見た目立ち方に応じて、オブジェクトの優先順位を決められます。

<a id="camera"></a>
## カメラ

焦点距離、カメラの高さ、遠近感、画面の占有率は、創作上の判断でありタスクに依存します。構図調整ツールやカメラの検査を使って要求された結果に合わせ、一律の室内、製品、映画風プリセットを強制しないでください。

必要なオブジェクトが見え、重要なシルエットが意図せず切れたり隠れたりしていないことを確認してください。カメラは構造的な誤りを隠せるため、視覚的な構図は空間検証の代わりにはなりません。

<a id="lighting"></a>
## 照明

想定する光源、雰囲気、マテリアルの反応、レンダーエンジンに合わせて照明を選んでください。スタジオ用プリセットは単独のアセットに対する有用な出発点ですが、窓、照明器具、屋外条件、様式的な演出を明示したシーンには、独自の照明やワールド環境が適する場合があります。

露出、色の分離、影の見やすさ、明部によってマテリアルの色が失われていないかを判断してください。照明のエネルギーの数値範囲は出発点であって、シーンに関係なく適用する規則ではありません。

<a id="acceptance"></a>
## 受け入れ判定

ツールの成功応答だけでなく、最終的なレンダリング成果物を確認してください。目に見える問題が残る場合は、無関係なシーン要素を作り直すのではなく、対象を絞って修正し、再レンダリングしてください。

`inspect_render_artifact` は画像の整合性を検査するものであり、画像が制作要件を満たすかどうかを判定するものではありません。クライアントの画像表示機能で画像を開いてください。表示できない場合は、視覚的な品質は未検証であることを明示してください。

要求された各オブジェクトや編集について、存在と比率、機能上の正面方向、接触や取り付け、クリアランス、可視性、マテリアルの判別しやすさを、ユーザーの意図と証拠に照らして比較してください。主要なカメラが疑わしい関係を隠している場合は、診断用の側面図や上面図を取得してください。境界に基づく支持の報告は、中空の支持物、回転した部品、取っ手、局所的なメッシュの衝突を見落とすことがあります。合格した報告を完全な受け入れ判定と見なすのではなく、実際のジオメトリと明示された意図に照らして解釈してください。修正後は影響を受けた関係を再確認してください。
