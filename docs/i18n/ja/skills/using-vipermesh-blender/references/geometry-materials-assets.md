# ジオメトリ、マテリアル、アセット

<a id="geometry-strategy"></a>
## ジオメトリの方針

要求された形状とその後の用途に基づいて方法を選んでください。

- 大まかな形状やハードサーフェス構造には、プリミティブと組み立てツール
- 経路、ケーブル、レール、断面形状から作る形には、カーブ
- 元に戻せる反復、平滑化、厚み付け、変形には、モディファイアー
- 密度の削減やトポロジーの変換には、リトポロジーツール
- 適切な直接操作がない独自のプロシージャルジオメトリには、`execute_code`

特定の方法をあらゆる場合に優れているものとして扱わないでください。破壊的な変換によって試行錯誤が難しくなる場合は、元のジオメトリを保持してください。

<a id="materials"></a>
## マテリアル

一般的な Principled BSDF やテクスチャの処理には、構造化されたマテリアルツールを使用してください。プレビューを超えて結果の正確さが重要になる場合は、テクスチャのパス、色空間、UV への依存関係、レンダーエンジンの挙動を確認してください。

マテリアルの値は、表現する物質、スケール、照明、アートディレクションに合わせて設定してください。既定値や物理的な範囲は有用な参考情報ですが、意図的な様式表現を上書きする理由にはなりません。

<a id="assets"></a>
## アセット

細かなジオメトリが特徴を決める複雑なオブジェクトを手作業で近似する前に、再利用できるアセットを探してください。可能であれば、複数のオブジェクトで構成されるアセットを管理用のルートを通してインポートし、配置先のシーンで境界、スケール、向き、支持状態を確認してください。

一致したアセットは候補であって、自動的に採用されるものではありません。ライセンス、スタイル、トポロジー、マテリアル、機能上の向きがタスクに適合するか確認してください。
