# キャラクター、アニメーション、エクスポート

<a id="character-work"></a>
## キャラクター制作

リトポロジー、UV、リグの生成、バインド、ウェイトの整理、アニメーションの準備は、それぞれ別の課題として扱い、段階の間で明示的に確認してください。オペレーターの呼び出しが成功しても、変形の品質や本番制作への適合性が証明されたわけではありません。

元のメッシュと用途に応じて、ポリゴン削減、ボクセルリメッシュ、QuadriFlow、または独自のトポロジー編集を選んでください。破壊的なトポロジー変更の前には、元の状態を保存してください。

リギングでは、スケール、トランスフォーム、メッシュの整合性、アーマチュアの位置合わせ、変形グループ、ウェイトの正規化、代表的な変形を確認してください。自動ウェイトは出発点にすぎず、十分かどうかはメッシュと動きによって異なります。

<a id="animation"></a>
## アニメーション

編集前にフレーム範囲、アクション、コンストレイント、ドライバー、ルートモーション、対象リグとの互換性を検査してください。リターゲットやベイクでは情報が失われることがあるため、復元可能な元データを残し、代表的なポーズや動きの区間を検証してください。

<a id="export"></a>
## エクスポート

一律のプリセットではなく、出力先の制作工程に合わせて形式とオプションを選んでください。エクスポート前に次を確認します。

- 意図したオブジェクトとコレクションが含まれているか
- トランスフォームとスケール
- トポロジーと法線
- UV、マテリアル、テクスチャへの依存関係
- アーマチュア、ウェイト、アクション、アニメーション範囲
- 適用または保持が必要なモディファイアーやコンストレイント

可能であれば、エクスポートされた成果物を検証してください。ファイルが保存されたというだけでは、別のアプリケーションが正しく読み込めることの十分な証拠にはなりません。
