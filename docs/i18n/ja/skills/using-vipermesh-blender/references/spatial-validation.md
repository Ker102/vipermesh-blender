<a id="spatial-validation"></a>
# 空間的な検証

<a id="read-world-space-state"></a>
## ワールド空間の状態を把握する

オブジェクトの原点やローカル寸法は、評価後のワールド空間での境界の信頼できる代わりにはなりません。回転、スケール、親子関係、モディファイアー、評価後のジオメトリによって、重要な表面の位置や形状は変わり得ます。

配置が重要な場合は、関連するオブジェクトを調べ、ワールド空間の境界、取り付け位置、実際の表面との交点から判断してください。

<a id="express-the-intended-relationship"></a>
## 意図した関係を表す

ユーザーの意図に合う検証を選んでください。

- 物理的な支持には `supported_by` または `on_top_of`
- 機能上の方向には、正面や向きの関係
- 必要な隙間には、クリアランスの確認
- 他のオブジェクトの内部にあるべきオブジェクトには、包含の確認
- 正確に接続する部品には、取り付け位置の整合

「上にある」という大まかな上下関係だけでは、接触は証明されません。見栄えのよいカメラ角度でも、オブジェクトが接地していることや、他の物体と交差していないことは証明できません。

<a id="use-recommendations-not-fixed-layouts"></a>
## 固定レイアウトではなく推奨事項を使う

適切なスケール、間隔、向きは、アセット、カメラ、アニメーション、対象プラットフォーム、制作上の意図によって異なります。役立つ場合は、参考寸法やクリアランスの範囲を判断の出発点にし、状況に合わせて調整してください。

近接配置の後は、奥行きや接触が分かる角度から確認してください。最終的な受け入れ判定の前に、浮き、意図しないめり込み、機能上の逆向き、支持の誤りを修正してください。
